# @tensorplay/xpuoj

Local MCP bridge for XPUOJ's browser-native Agent Relay.

```bash
npm install --global @tensorplay/xpuoj
xpuoj mcp
```

When an XPUOJ tool is first used, open the requested XPUOJ page, press
<kbd>Ctrl</kbd>+<kbd>B</kbd>, keep the relay URL at `http://127.0.0.1:7423`, and click
**Connect**. No browser extension is needed. Your XPUOJ login remains in the browser. Chrome,
Edge, Firefox, Safari, and other modern browsers are supported. In Chrome or Edge, allow XPUOJ's
**Local network access** permission when prompted.
